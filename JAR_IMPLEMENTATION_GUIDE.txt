📦 WHAT THIS FEATURE DOES

Unzip JAR/ZIP Files:
  ✓ Upload JAR or ZIP files
  ✓ Automatically extract contents
  ✓ Temporary extraction (cleaned up after analysis)

Classify Files By:
  ✓ Name (file names)
  ✓ Type (extension: .class, .jar, .properties, etc.)
  ✓ Size (formatted: Bytes, KB, MB, GB)
  ✓ Date (last modified date)
  ✓ Count (total files and folders recursively)

Display Results:
  ✓ Summary cards with statistics
  ✓ File type distribution badges
  ✓ Detailed file list with metadata
  ✓ Hierarchical folder structure
  ✓ Expandable accordion for subfolders

🔧 CONFIGURATION

To Change File Size Limit:
  1. Open: backend/routes/jar.js
  2. Find: limits: { fileSize: 500 * 1024 * 1024 }
  3. Change: 500 to desired MB value
  4. Restart: npm start
