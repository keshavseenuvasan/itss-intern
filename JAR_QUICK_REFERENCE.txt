WHAT CAN IT DO?
═══════════════════════════════════════════════════════════════════════════════

✓ Unzip JAR files
✓ Unzip ZIP files
✓ Extract all contents
✓ Analyze file structure
✓ Count total files
✓ Count total folders
✓ Classify by file type (extension)
✓ Show file sizes (formatted)
✓ Show last modified dates
✓ Display in hierarchy
✓ Expandable subfolders
✓ File type summary with counts


HOW TO USE (QUICK)
═══════════════════════════════════════════════════════════════════════════════

1. cd backend && npm install
2. npm start
3. Open http://localhost:5000
4. Login: demo / demo123
5. Click "📦 Analyze JAR/ZIP" tab
6. Select a .jar or .zip file
7. Click "Analyze"
8. View results!


RESULT SUMMARY
═══════════════════════════════════════════════════════════════════════════════

You'll see:

📊 Summary Cards:
   • Total Files: Count of all files
   • Total Folders: Count of all folders
   • Total Size: Combined size
   • File Types: Count of unique types

📦 File Type Summary:
   .class: 500 files
   .jar: 25 files
   .properties: 10 files
   .xml: 8 files

📄 File List:
   Name | Type | Size | Date | Path

📁 Folders:
   Expandable sections showing subfolders


SUPPORTED FILES
═══════════════════════════════════════════════════════════════════════════════

.jar - Java Archive files
.zip - ZIP compressed files
Max size: 500 MB


WHAT GETS CLASSIFIED
═══════════════════════════════════════════════════════════════════════════════

For Each File:
  ✓ File name
  ✓ File type (extension)
  ✓ File size (Bytes/KB/MB/GB)
  ✓ Last modified date
  ✓ Path within archive

Summary:
  ✓ Total file count (recursive)
  ✓ Total folder count (recursive)
  ✓ Total size
  ✓ File type distribution

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Invalid file type"
  → Make sure file ends in .jar or .zip

"File too large"
  → File exceeds 500MB limit

"Upload failed"
  → Check file is not corrupted
  → Try a different file

"No results"
  → File may be empty
  → Try a different JAR
