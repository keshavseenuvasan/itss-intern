TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Access denied" error
→ Folder not in allowed paths. Use suggested paths or contact admin.

Problem: Analysis takes very long
→ Folder is very large. This is normal. Wait for completion.

Problem: "Permission denied" for some folders
→ Windows restriction (system folders). These are skipped but analysis continues.

Problem: Tree view not showing
→ Either empty folder or loading. Try expanding other folders.

Problem: No files shown
→ Folder is empty or contains only subfolders.
