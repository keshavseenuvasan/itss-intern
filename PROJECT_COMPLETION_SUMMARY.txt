SUPPORT & HELP
═══════════════════════════════════════════════════════════════════════════════

Common Issues:

Q: "Access denied" error
A: Folder not in allowed paths. See ENHANCED_FOLDER_ANALYZER_GUIDE.md

Q: Analysis taking long
A: This is normal for large folders (>1GB). See performance metrics.

Q: Tree view not showing
A: Try expanding other folders. Empty folders have no tree items.

Q: Dates not showing
A: Check browser console for errors. Try different folder.

Q: Mobile not working
A: Clear browser cache. Try different browser.
