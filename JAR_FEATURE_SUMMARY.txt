📋 HOW TO USE JAR ANALYSIS

1. Login to dashboard
2. Click "📦 Analyze JAR/ZIP" tab
3. Click "Select JAR/ZIP File"
4. Choose a .jar or .zip file (max 500MB)
5. Click "Analyze"
6. Wait for results
7. View:
   - Total files, folders, size
   - File type distribution
   - File list with metadata
   - Folder structure

🔧 TECHNICAL DETAILS

Backend Libraries Used:
  • adm-zip (0.5.10) ........... ZIP/JAR extraction
  • multer (1.4.5) ............. File upload handling
  • Node.js fs module .......... File metadata
  • Node.js path module ........ Path handling

Key Functions:
  • analyzeJarFile() ........... Extract and analyze JAR
  • analyzeDirectory() ......... Recursive directory analysis
  • calculateTotalStats() ...... Calculate overall statistics
  • formatFileSize() ........... Format bytes to readable format

API Endpoints:
  POST /api/jar/analyze ........ Upload and analyze JAR file

File List:
  ✓ Name
  ✓ Type (extension)
  ✓ Size (formatted)
  ✓ Last modified date
  ✓ Relative path in archive

Folder Structure:
  ✓ Hierarchical display
  ✓ Expandable sections
  ✓ Nested file and folder analysis

🔒 SECURITY FEATURES

✅ File Type Validation
   - Only .jar and .zip files accepted
   - Extension checking on server

✅ Size Limits
   - Maximum 500MB per file
   - Prevents memory issues

✅ Authentication
   - Requires valid JWT token
   - Protected endpoint

✅ Temporary Storage
   - Files extracted to temp directory
   - Automatically deleted after analysis
   - No permanent storage

✅ Safe Extraction
   - No path traversal attacks possible
   - Safe directory operations

✨ FILE CLASSIFICATION SYSTEM

Files are classified by extension:

Code Files:
  .class, .java, .scala, .kt, .groovy, .properties

Archive Files:
  .jar, .zip, .war, .ear, .rar, .7z

Data Files:
  .xml, .json, .csv, .yml, .yaml, .properties

Documentation:
  .md, .txt, .html, .htm, .doc, .docx

Media:
  .jpg, .jpeg, .png, .gif, .mp3, .mp4, .pdf

Configuration:
  .conf, .config, .ini, .env, .gradle, .maven

🔧 CONFIGURATION

To modify JAR analysis settings:

File Size Limit:
  Location: backend/routes/jar.js
  Parameter: limits: { fileSize: 500 * 1024 * 1024 }
  Change: Modify 500 to your desired MB value

Temp Directory:
  Location: backend/utils/jarAnalyzer.js
  Uses: OS temp directory (automatic)
  Cleanup: Automatic after analysis
